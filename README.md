# 电动汽车充电桩应用管理平台

基于 Linux（Ubuntu 22.04）+ Qt 6 的智慧充电运营平台，覆盖「用户端—管理端—数据端—大屏—机器学习」全链路：车主找桩、预约、充电、结算，运营方管设备、看营收、排故障，机器学习把充电时序数据转化为负荷预测、故障预测与调度建议，最终在 Web 大屏上以运营驾驶舱呈现。

## 五大子系统

| 子系统 | 运行形态 | 面向对象 |
| ------ | -------- | -------- |
| 充电用户端 | Linux + Qt 桌面程序（QML，模拟手机交互） | 电动汽车车主 |
| 服务器管理端 | Linux + Qt 桌面程序（Widgets，宽屏后台） | 运营管理员 |
| 数据库端 | QSQLite 单文件，全业务数据核心 | 各端共享 |
| 大数据可视化大屏 | Web 页面（ECharts），运营驾驶舱 | 运营决策者 |
| 机器学习智能分析 | C++ 规则 + 仿真数据（可附加最小 FastAPI） | 各端共享能力层 |

## 技术栈

- Ubuntu 22.04（VMware 17 虚拟机）
- Qt Creator 6.2+ / C++（用户端 QML + 管理端 Widgets）
- QSQLite 数据存储
- WebSocket + JSON 全端统一通信（服务端为无界面 C++ 进程）
- QThread + QTimer 多线程
- ECharts 大屏可视化
- 腾讯地图 Web API / QWebEngineView 地理编码与导航
