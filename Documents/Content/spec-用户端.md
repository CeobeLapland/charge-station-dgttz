# spec-用户端

运行形态：Linux + Qt 桌面程序，QML 模拟手机端交互（竖屏窗口、圆角卡片、渐变动画）。面向对象：电动汽车车主。所有消息类型、字段、枚举以 `spec-协议.md`、`spec-数据库.md` 为准，UI 实现遵循 `AGENTS.md` 规范。

## 页面清单

| 页面 | 入口 | 说明 |
| ---- | ---- | ---- |
| 登录页 | 启动 | 手机号免密登录 |
| 首页（附近电站） | 登录后 | 电站列表，默认落点 |
| 电站详情 | 点击电站卡片 | 电桩明细 + 分时电价 + 避峰提示 + 费用与设施【增强】 |
| 充电过程页 | 选择空闲桩开始 | 实时进度面板 |
| 订单列表 / 订单详情 | 底部「订单」 | 含时间轴、报告、绿色贡献 |
| 我的 | 底部「我的」 | 头像、昵称、余额、画像、积分、会员、我的车辆【增强】、优惠券【增强】 |
| 结算页 | 充电结束 | 汇总、扣款、报告、积分 |
| 排队页 | 电站无空闲桩 | 排队列表 + 预计等待 |
| 评价页【增强】 | 订单完成后 / 我的 | 站点多维评分 + 标签 + 有用 |
| 客服与工单页【增强】 | 我的 | 问题分类 + 工单提交/进度 |

主导航：底部「充电」「订单」「我的」三入口。增强页从「我的」或订单流程进入。

## 功能规格

### 手机号免密登录【基础】

- 触发：登录页提交 11 位手机号。
- 规则：非 11 位数字时禁用登录按钮并在输入框下方提示；查询 `user.phone`，已存在则直接登录并读回昵称/头像/余额；不存在则自动建号（昵称"用户"+后四位，头像灰色占位，余额 0）后登录。
- 消息：`user.login` / `user.login_resp`（见协议）。
- 验收：不存在手机号首次登录后，数据库新增一条 user，进入首页且首页展示正确昵称与余额。

### 用户信息展示与修改【基础】

- 触发：进入「我的」页。
- 规则：展示头像、昵称、手机号（只读）、余额。可操作：换头像（本地选图后上传/保存路径）、改昵称（非空且 2–20 字符）、充值（输入金额，模拟支付成功弹窗，余额实时累加，不产生订单）。
- 消息：`user.info`、`user.recharge`、`user.update_profile`。
- 验收：改名后会话内昵称与数据库同步；充值后余额即时更新；非 2–20 字符昵称保存被拒绝并提示。

### 用户充电画像【增强】

- 触发：进入「我的」页底部。
- 规则：由历史订单聚合：月均充电次数、平均单次充电量、最常到访站、常用时段、偏好类型。订单结算后刷新。
- 消费方：智能推荐、避峰提示引用画像（如"常用时段 18:00–21:00"）。
- 验收：有历史订单的用户，画像各字段非空且与订单统计一致。

### 我的车辆与兼容性【增强】

- 触发：首次进入「我的」或智能推荐前。
- 规则：用户可添加多辆车，字段：车辆名称、车型（乘用车/轻商/两轮/三轮）、电池容量（kWh）、接口类型（国标交流/国标直流/其他）、最大支持功率（kW）。系统按车型与接口过滤可用桩；推荐时自动计算"当前电量 → 目标电量"所需电量（目标差 × 电池容量），作为费用与等待预估输入。
- 数据：`vehicle` 表（见 spec-数据库）。
- 消息：`vehicle.add` / `vehicle.list` / `vehicle.update`（见 spec-协议 增强消息）。
- 验收：添加车辆后，电站/桩列表只展示接口兼容的桩；推荐页按车辆电量估算所需充电量。

### 站点费用与设施【增强】

- 触发：进入电站详情页。
- 规则：除电价外展示：服务费（元/kWh）、停车费（元/小时）、营业时间；设施勾选：洗手间、便利店、休息区、Wi-Fi、雨棚、地下停车场。与"停车信息"一起决定"要不要开过去"。
- 数据：`station` 扩展字段或 `price_rule` 邻近配置（见 spec-数据库）。
- 验收：详情页费用与设施齐全，且与推荐排序（如雨天优先室内/有雨棚站）联动。

### 天气影响推荐【增强】

- 触发：首页/推荐/电站详情。
- 规则：接入天气（可模拟）：降雨时优先推荐室内/有雨棚站并提示；高温时提示设备温度偏高、预计充电时间可能延长；极端天气给出风险提醒并建议室内站。天气同时作为负荷预测输入（见 spec-机器学习）。
- 验收：模拟降雨后推荐排序优先室内/雨棚站，详情页出现对应提示。

### 附近充电站查询【基础】

- 触发：进入首页。
- 规则：定位由软件模拟——下拉选区域或手动输入地址，经腾讯地图 Web API 转经纬度；按距离近→远排序；卡片显示站名、价格（元/度）、空闲/总桩数、距离（km）。点击卡片进入电站详情，逐桩显示编号、类型、状态、功率。
- 消息：`station.nearby` / `station.nearby_resp`、`station.detail` / `station.detail_resp`。
- 验收：列表按距离升序；卡片字段齐全；详情桩状态与 `charger.status` 一致。

### 一键导航【基础】

- 触发：点击电站卡片的距离信息。
- 规则：以当前位置为起点、目标电站坐标为终点，QWebEngineView 加载腾讯地图路线规划，提供驾车/步行方式。
- 验收：点击后弹出地图路线规划页，起终点正确。

### 智能充电推荐【增强】

- 触发：在首页输入约束或点推荐入口。
- 规则：输入项（可默认）：当前电量、目标电量、最长等待、价格策略、充电方式、是否绕路及上限。系统对候选站按距离、空闲桩、排队、价格、预计等待/充满时间、拥堵预测、健康度打分（0–100），输出推荐卡：站名、评分、距离、空闲数、预计等待、预计充满、预计费用、一句理由；给出"最快/最省钱/综合最优"三快捷标签。
- 消息：`station.recommend` / `station.recommend_resp`。
- 评分权重 `[待定]`（见文末清单）。
- 验收：推荐结果包含全部输出字段；点击三标签切换对应排序。

#### 猜你喜欢【增强】

- 触发：首页推荐区/推荐结果页顶部。
- 规则：基于画像（历史充电站、常用时间、车型、价格偏好、常去区域）给出"猜你会喜欢"卡片：站名、评分、距离、一句理由（如"您已充电 14 次""价格比常用站低 12%""距离下班路线 300m"）。与智能推荐共用排序逻辑，仅展示维度不同。
- 验收：有历史订单的用户，猜你喜欢卡片出现且理由可追溯画像数据。

### 一键找空闲桩【增强】

- 触发：点击"帮我找一个现在最快能充上的桩"。
- 规则：跳过输入，按"距离近、无需排队、当前空闲、快充优先"返回一个最优桩：编号、距离、排队状态、功率、状态、预计费用。
- 验收：返回的桩当前状态为 idle（无空闲时返回最接近者并标注排队）。

### 充电站排队预约【增强】

- 触发：目标站无空闲桩。
- 规则：显示排队人数与预计等待；给出"若现在预约"时间线（加入时间、预计开始时间）；提供"加入智能排队"。排队页展示"充电中"列表（桩号+SOC）与"预约队列"（序号+预计开始）。有空桩时按队列通知。
- 消息：`reservation.join` / `reservation.join_resp`、`reservation.cancel`、`push.reservation_notify`。
- 验收：加入后产生 reservation 记录（waiting）；桩空出后收到通知并可按序充电。

### 动态电价与错峰充电【增强】

- 触发：进入电站详情页。
- 规则：显示当前时段实时电价 + 谷/平/峰三档价表；当处于高峰时提示；给出"延后充电可省金额"估算（目标电量 × 档位价差）。
- 数据：`price_rule` 表。
- 验收：电价按当前时间正确取档；省钱估算数值可复算。

### 智能避峰推荐【增强】

- 触发：浏览电站详情或推荐时。
- 规则：读取负荷预测的未来 2 小时曲线与拥堵预测，判断目标站将进入高峰时提示（如"预计 17:00 进入高峰，提前充电可减少等待 21 分钟"），页面标注"基于负荷预测"。
- 消费方：`spec-机器学习` 负荷预测。
- 验收：在预测高峰前展示提示，文案含"基于负荷预测"。

### 预计等待时间【增强】

- 触发：电站列表/详情/排队页。
- 规则：把"空闲 5/20"升级为"预计等待 N 分钟"；根据当前队列与历史同期预测 10 分钟、20 分钟后等待时间，输出"现在去 / 10 分钟后 / 20 分钟后"三档并给"建议现在前往"结论。
- 数据：排队与历史负荷数据，算法见 `spec-机器学习`「等待时间预估」。
- 验收：等待时间随队列变化更新；三档时间与结论可复算。

### 充电前检查与选桩【基础】

- 触发：进入充电流程。
- 规则：查询当前用户是否存在 `charging` 状态订单——存在则弹窗"您有未完成的充电订单，请先结算"并强制跳结算页；不存在则选空闲桩开始。
- 消息：`order.create` / `order.create_resp`。
- 验收：存在未结算订单时无法发起新充电，且跳转结算页。

### 充电过程模拟与实时跟踪【增强】

- 触发：开始充电。
- 规则：充电面板展示当前电量、目标电量、预计时间、预计 kWh、预计费用、当前功率、预计完成时间；进度条 + 数字实时更新。充电曲线两段式模拟：0–80% 快充功率快速上升，80% 后功率下降。每段数据（电量/时长/功率/费用）逐笔写入订单与 `charging_measure`。
- 消息：`order.start`、`push.order_progress`。
- 验收：进度实时递增且曲线在 80% 附近斜率变化；测量数据落库。

### 充电异常提醒【增强】

- 触发：充电中或结束后异常事件。
- 规则与提示文案：

| 事件 | 提示内容 |
| ---- | -------- |
| 充电中断 | 充电已中断，若未恢复请查看设备状态或联系管理员 |
| 功率异常下降 | 检测到功率异常下降，正在监控 |
| 设备离线 | 充电设备已离线，系统正在尝试恢复 |
| 充电完成 | 车辆已达到目标电量，继续占用将产生占位费用 |
| 长时间占位 | 检测到结束后长时间占用，可能产生占位费 |

- 联动：与管理端设备状态、告警一致。
- 验收：模拟对应事件时，用户端出现对应提示。

### 订单结算【基础】

- 触发：充电结束（主动结束或达目标电量）。
- 规则：汇总充电量、时长、费用；按分时电价计费并扣除余额；余额不足提示引导充值；结算后订单转 `completed` 不可再改。
- 消息：`order.finish` / `order.settle`。
- 验收：结算后余额扣减正确、订单为 completed、可读不可改。

### 充电订单时间轴【增强】

- 触发：打开订单详情。
- 规则：按时间顺序展开节点：预约成功 → 到达充电站 → 开始充电 → 达到 50% → 达到目标电量 → 充电结束 → 自动结算，每节点带时间戳。
- 验收：时间轴节点与订单实际状态变化对应。

### 智能充电报告【增强】

- 触发：结算完成后。
- 规则：本次数据（充电量/时长/平均功率/总费用）+ 与本站近期平均对比（速度/费用/等待差异）+ 一句体验评价（按速度、费用、等待在本站历史分位计算）。
- 体验评价算法 `[待定]`。
- 验收：报告含两组数据与一句评价，对比数值有据可查。

### 绿色充电贡献【增强】

- 触发：报告页。
- 规则：展示本次充电量、估算减碳量（充电量 × 碳排因子）；个人累计减碳在「我的」汇总。
- 碳排因子 `[待定]`（建议初值 0.7 kg/kWh，见 spec-机器学习）。
- 验收：本次与累计减碳数值正确换算。

### 积分与会员【增强】

- 触发：结算成功 / 充电前。
- 规则：完成充电获得积分（结算页即时提示"+42 积分"）；积分可抵扣充电费；低峰时段充电多倍积分（充电前提示"现在充电可获得 2 倍积分"）；会员等级（normal/vip/enterprise）影响积分倍率与优惠。
- 数据：`point_record`、`user.points`。
- 积分规则 `[待定]`。
- 验收：充电后 `point_record` 新增一条，余额抵扣可用。

### 优惠券【增强】

- 触发：进入「我的」→ 优惠券；结算页选券。
- 规则：展示平台下发的券：新人立减、满减券（如满 50 减 5）、夜间充电券、指定站点/时段券。每张显示券名、面额、门槛、适用范围、有效期、状态（未使用/已使用/已过期）；结算页可选一张未过期券抵扣，抵扣后核销。领券由营销活动或服务端下发（新人券首次登录自动发放）。
- 数据：`coupon`、`user_coupon` 表（见 spec-数据库）。
- 消息：`coupon.list` / `coupon.list_resp`、`coupon.claim` / `coupon.claim_resp`；`order.settle` 携带 `coupon_id` 抵扣。
- 验收：领券后在结算页可选择抵扣，实付金额 = 应收 − 面额且不超门槛规则；用后券转已使用。

### 站点评价【增强】

- 触发：订单完成后 / 「我的」评价入口。
- 规则：对订单关联电站提交多维评分：综合、充电速度、设备状况、停车便利、卫生环境、服务态度（0–5）；可打标签（充电快/车位宽敞/晚上人少/停车费高/设备老旧/适合快充/排队严重等）；可写文字评价。其他用户可点"有用"（+1）。评价数据供大屏与管理端分析（见 `spec-大屏`「评价与反馈分析」）。
- 数据：`review` 表（见 spec-数据库）。
- 消息：`review.create` / `review.create_resp`、`review.list` / `review.list_resp`、`review.useful` / `review.useful_resp`。
- 验收：提交后评价入库并在站点详情展示；点有用后计数 +1；标签参与分析口径。

### 客服与工单【增强】

- 触发：「我的」→ 客服/投诉入口。
- 规则：问题分类：充电异常、订单问题、退款问题、设备故障、预约问题、其他。选择分类后可提交工单（附描述）；工单产生后服务端实时推送管理端，用户可在工单列表查看状态流转（待处理→处理中→已完成/已关闭）。
- 数据：`work_order` 表（见 spec-数据库）。
- 消息：`work_order.create` / `work_order.create_resp`、`work_order.list` / `work_order.list_resp`、`push.work_order`。
- 验收：提交工单后管理端实时出现新工单；处理后在用户端看到状态更新。

## 订单状态机

| 当前状态 | 允许操作 | 下一状态 | 触发条件 |
| -------- | -------- | -------- | -------- |
| 预约中 | 取消预约 / 到站开始充电 | 已取消 / 充电中 | 用户取消 / 到位并选中空闲桩 |
| 充电中 | （仅监控）结束充电 | 待结算 | 用户结束或达到目标电量 |
| 待结算 | 结算 | 已完成 | 余额扣除成功 |
| 已完成 | 查看报告（只读） | — | 终态 |
| 已取消 | — | — | 终态 |

## UI 要求（QML）

- 竖屏窗口 + 底部三导航；卡片用圆角 + 渐变；页面切换用 StackView 过渡动画。
- 顶部沉浸式状态栏：头像、昵称、余额。
- 充电过程页用 ProgressBar + NumberAnimation 数字跳动。
- 导航地图用 QWebEngineView 加载腾讯地图。
- 状态色块口径与 `spec-管理端` 设备状态一致（绿空闲/蓝充电/黄预约/红故障/灰离线）。

## 待定项清单

| 项 | 建议初值 |
| --- | -------- |
| 智能推荐评分权重 | 距离 0.3 / 价格 0.3 / 等待 0.2 / 健康度 0.2 |
| 体验评价分位算法 | 本次速度/费用/等待在本站历史中的百分位均值 |
| 碳排因子 | 0.7 kg CO2/kWh |
| 积分发放规则 | 基础 1 积分/元，低峰 ×2，VIP ×1.5 |
