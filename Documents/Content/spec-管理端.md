# spec-管理端

运行形态：Linux + Qt 桌面程序，Qt Widgets 宽屏后台风格，以表格、图表为主，深色 QSS 主题。面向对象：运营管理员。所有消息类型、字段、枚举以 `spec-协议.md`、`spec-数据库.md` 为准。

## 页面清单

| 页面 | 说明 |
| ---- | ---- |
| 登录 | 管理员账号/密码 |
| 运营驾驶舱【增强】 | 登录后首页：今日营收/订单/充电量/在线率/利用率/用户增长 + 趋势 |
| 销售业绩 | 营收折线 + 指标卡 |
| 电桩状态 | 状态分布 + 占比 |

| 充电站管理 | 电站列表、详情、新增 |
| 站点运营分析【增强】 | 单站利用率/日均订单/营收/故障率/等待/评分 + 高峰时段 |
| 设备运维 | 健康度、故障处置、数字孪生 |

主界面左侧功能导航，顶部常驻管理员身份与退出，右下角挂 AI 助手入口。

## 功能规格

### 管理员登录【基础】

- 触发：输入账号/密码。
- 规则：校验 `admin` 表，默认初始 `admin / 123456`；错误给出明确提示且不进入。登录态会话内保持。
- 消息：`admin.login` / `admin.login_resp`。
- 验收：正确凭据进入主界面，错误凭据被拒绝。

### 运营驾驶舱【增强】

- 触发：管理员登录后默认落点（登录后不进用户管理，先进驾驶舱）。
- 规则：顶排指标卡：今日营收、今日订单、充电量（kWh）、设备在线率、平均利用率、用户增长（+%）。下方趋势区：营收趋势、订单趋势、负荷曲线、站点排名（TOP）。指标随设备/订单实时刷新。
- 数据口径：与 `spec-大屏` 驾驶舱共用，保证数字一致。
- 消息：`admin.cockpit` / `admin.cockpit_resp`；增量 `push.charger_status`、`push.alarm`、`push.order_event`。
- 验收：登录后进入驾驶舱，各指标与数据库统计一致，随推送实时更新。

### 销售业绩【基础】

- 触发：进入销售业绩页。
- 规则：QChart 折线图展示近 7 日/近 30 日营收趋势（可切换）；指标卡并列今日营收、本月营收、总营收，随筛选联动。
- 消息：`admin.revenue` / `admin.revenue_resp`。
- 验收：切换时间维度图表与指标同步更新；数值与订单结算金额一致。

### 峰谷电量与减碳表现【增强】

- 触发：销售业绩页扩展区。
- 规则：各时段充电量占比与变化趋势；今日减碳量、累计减碳量。口径与 `spec-大屏` 绿色指数共用，保证数字一致。
- 验收：管理端与大屏减碳数字一致。

### 电桩状态分布【基础】

- 触发：进入电桩状态页。
- 规则：表格展示在用/闲置/故障三类数量与占比百分比 + 占比图；随设备状态实时刷新；离线桩计入"离线"口径。
- 消息：`admin.station_status` / `admin.station_status_resp` + `push.charger_status`。
- 验收：状态数量与 `charger.status` 实时一致，占比合计 100%。

### 充电桩管理【基础】

- 触发：进入充电桩管理页。
- 规则：列表字段：电桩编号、所属电站、类型、功率、当前状态、累计充电次数、累计充电时长。选中后执行远程重启：模拟向桩发送重启指令，桩状态短暂"重启中"后回到目标状态，全程写入 `device_log`。
- 消息：`admin.charger_restart`、`push.device_log`。
- 验收：重启后 `device_log` 新增 success 记录，桩状态经 rebooting 回到正常。

### 充电站管理【基础】

- 触发：进入充电站管理页。
- 规则：列表字段：ID、站名、地址、经纬度、总桩数、在线率。点击行看站内全部电桩实时明细；新增电站表单（站名、地址、经纬度、桩数），地址可经腾讯地图 Web API 反查经纬度。
- 消息：`admin.station_list` / `admin.station_list_resp` / `admin.station_add`。
- 验收：新增后电站入库并可查询；在线率按在线桩数/总桩数计算。

### 站点运营分析【增强】

- 触发：充电站管理选中某站 → 「运营分析」。
- 规则：单站指标卡：利用率、日均订单、日均营收、故障率、平均等待时间、用户评分；下方高峰时段柱状图（逐时利用率/订单，运营一眼看出该站何时忙、何时空）。
- 数据：订单、`charging_measure`、`review` 聚合。
- 消息：`admin.station_analysis` / `admin.station_analysis_resp`。
- 验收：任一站的指标与订单/测量数据统计一致，高峰时段图与时段订单分布一致。

### 设备健康度与智能诊断【增强】

- 触发：打开设备详情。
- 规则：每桩维护健康度 0–100，综合通信状态、温度、功率稳定性、近期异常次数。详情拆解：健康度分、运行状态、通信/温度/功率各维度、最近异常时间。健康度低于阈值时给出疑似故障结论与异常概率，并在列表醒目标记。
- 健康度公式与阈值 `[待定]`（见 spec-机器学习）。
- 验收：异常桩在列表标记；详情展示各维度指标。

### 设备健康中心【增强】

- 触发：进入设备健康中心页。
- 规则：顶部汇总卡：设备总数、正常、预警、故障、离线；下方健康度排名列表（桩号 + 健康分 + 状态标记，健康度 < 60 红色、< 80 黄色）；点击设备查看历史：历史故障、历史充电次数、平均功率、工作时长、最近维护、故障频率。
- 数据：`charger.health_score`、`device_log`、`charging_measure` 聚合。
- 消息：`admin.charger_list` / `admin.charger_list_resp`（扩展 health_score）、`admin.fault_risk` / `admin.fault_risk_resp`、`admin.device_log` / `admin.device_log_resp`。
- 验收：健康度排名与公式可复算，预警/故障桩醒目标记，单设备历史有据可查。

### 模拟故障与远程运维【增强】

- 触发：设备故障或演示触发模拟故障。
- 规则：故障时桩状态转"异常"并弹告警；详情给出建议操作：远程重启 / 暂停使用 / 安排人工检修。远程重启展示指令下发进度与结果；暂停使用从可用桩剔除；人工检修生成检修工单。所有动作写 `device_log`，用户端与大屏同步更新。
- 消息：`push.alarm`、`admin.charger_restart` / `admin.charger_pause`、`push.device_log`。
- 验收：故障后跨端状态一致；三种处置动作均产生对应日志与状态变化。

### 数字孪生充电站【增强】

- 触发：电站详情切「数字孪生」视图。
- 规则：平面图模拟停车场布局，桩位色块：绿空闲/蓝充电/黄预约/红故障/灰离线；点击桩位弹实时参数：功率、电压、电流、SOC、时长、温度、故障码、关联订单。本质为自定义 `QWidget::paintEvent` 绘制色块 + 点击弹窗。
- 验收：桩位颜色与 `charger.status` 一致，点击弹出实时参数。

### 用户管理【基础】

- 触发：进入用户管理页。
- 规则：列表字段：ID、手机号、昵称、余额、注册时间、状态。可冻结/解冻（冻结后无法充电与预约）；按手机号模糊搜索。
- 消息：`admin.user_list` / `admin.user_toggle_status`。
- 验收：冻结后该用户登录被拒（错误码 1003）；搜索按手机号子串命中。

### 用户画像【增强】

- 触发：用户管理点某用户 → 「画像」。
- 规则：展示画像标签（高频充电/快充偏好/晚间充电/价格敏感型等）、月均充电次数、平均金额、常用站点、最近 30 天充电次数、生命周期（活跃/流失）、价值等级（A/B/C）、最近一次充电时间。
- 数据：该用户历史订单聚合。
- 消息：`admin.user_portrait` / `admin.user_portrait_resp`。
- 验收：画像各字段由该用户历史订单聚合，数值可复算。

### 智能风控【增强】

- 触发：进入风控工作台。
- 规则：监测异常行为（如短时间内大量预约并频繁取消），对触达条件用户计算风险评分并标注等级（低/中/高）。单用户展示：等级、异常行为明细、评分。处置动作：限制预约 / 冻结 / 忽略。
- 规则阈值 `[待定]`（建议初值：24 小时预约 ≥ 10 次且取消率 ≥ 60% 触发）。
- 验收：构造高频预约取消数据后，用户被识别并展示明细与评分。

### 运营告警中心【增强】

- 触发：进入告警中心页 / 收到 `push.alarm`。
- 规则：汇总系统主动产生的告警：站负载 > 90%、设备连续功率异常、排队 > 10 人、站在线率 < 80%、用户异常取消预约等。列表展示级别（红/橙/黄）、类型、对象（站/桩）、时间、状态；管理员点击处理（重启 / 暂停 / 检修 / 忽略），处理后状态转 `handled`。
- 消息：`admin.alarm_list` / `admin.alarm_list_resp`、`admin.alarm_handle` / `admin.alarm_handle_resp`、`push.alarm`。
- 验收：模拟触发条件后告警自动产生并出现在中心；处理后状态与 `alarm.status` 一致。

### 工单中心【增强】

- 触发：进入工单中心页 / 收到 `push.work_order`。
- 规则：工单类型：用户投诉 / 设备故障 / 退款申请 / 设备维护 / 异常订单；状态：待处理 / 处理中 / 已完成 / 已关闭。列表按时间与优先级排序，待处理醒目标记（"待处理工单：N"）；处理流转：待处理 → 处理中 → 已完成 / 已关闭，可填处理结果。
- 消息：`admin.work_order_list` / `admin.work_order_list_resp`、`admin.work_order_handle` / `admin.work_order_handle_resp`、`push.work_order`。
- 验收：用户端提交工单后，管理端实时出现新工单；处理后状态同步到用户端。

### 营销中心【增强】

- 触发：进入营销中心页。
- 规则：券模板管理：新建/启停新人立减券、满减券、夜间优惠券、指定站点/时段券；活动统计：曝光、领取、使用、带来订单增长（+%）。
- 消息：`admin.coupon_create` / `admin.coupon_create_resp`、`admin.marketing_list` / `admin.marketing_list_resp`。
- 验收：新建券模板后用户端可领取并在结算使用；统计数字与领取/使用记录一致。

### AI 运营助手【增强】

- 触发：右下角对话入口。
- 规则：管理员自然语言提问，助手把数据库经营/设备数据转为可读结论，并引用负荷预测、故障预测结果。回答必须可追溯到真实数据记录。
- 消息：`admin.assistant_query` / `admin.assistant_query_resp`。
- 验收：典型问题（最高负载站、收入下降原因、最需检修桩）均给出引用真实数据的回答。

### what-if 决策仿真【增强】

- 触发：运营决策页输入假设。
- 规则：假设类型：加/减充电桩、电价调整、设备故障规模、客流变化。输出对平均等待时间、峰值利用率、预计日订单、预计日营收的推演，以下降/上升对照展示。
- 推演模型：与 `spec-机器学习` 需求模型共用。
- 消息：`admin.whatif` / `admin.whatif_resp`。
- 验收：任选一种假设，输出包含四项指标及对照变化。

## 设备状态口径

| 设备状态 | 含义 | 可执行操作 |
| -------- | ---- | ---------- |
| 空闲 | 当前无充电任务，可被用户选用 | 无 |
| 在用 | 正在执行充电任务 | 查看实时参数 |
| 预约 | 已被预约、等待用户到位 | 查看预约信息 |
| 故障 | 设备异常 | 远程重启 / 暂停使用 / 安排检修 |
| 离线 | 通信中断、无法上报数据 | 远程重启 / 安排检修 |
| 重启中 | 已下发重启指令、等待反馈 | 无 |

## UI 要求（Widgets）

- 统一深色 QSS 主题（背景建议 `#141a21` 一类），表格用色块标记状态（绿/蓝/黄/红/灰对应设备状态）。
- 营收用 QChart；数字孪生用自定义 paintEvent。
- 各页面共享"表格列表 + 详情弹窗 + 操作按钮"交互模式。

## 待定项清单

| 项 | 建议初值 |
| --- | -------- |
| 健康度公式 | 100 − 温度惩罚 − 通信惩罚 − 功率波动惩罚 − 异常次数（见 spec-机器学习） |
| 故障阈值 | 健康度 < 60 判定异常 |
| 预警阈值 | 健康度 < 80 标记预警 |
| 风控触发规则 | 24 小时预约 ≥ 10 次且取消率 ≥ 60% |
| 检修工单落库 | 建议复用 `device_log` action=repair |
